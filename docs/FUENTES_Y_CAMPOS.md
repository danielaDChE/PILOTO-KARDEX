# Fuentes utilizadas para construir el prototipo

El prototipo fue armado a partir de los documentos entregados para el levantamiento:

- **BOLETA DE REQUISITOS KARDEX 2026.docx:** catálogo de 25 requisitos de ingreso y plazo indicado de cinco días hábiles.
- **FICHA PERSONAL 2026.docx:** datos personales, contacto de emergencia, formación académica y datos institucionales/bancarios/seguridad social.
- **HOJA DE VIDA SEDEGES 2026.doc:** datos personales, estudios, cursos/seminarios, experiencia laboral, referencias personales, cuenta Banco Unión y fecha CENVI.
- **FORMULARIOS NUEVOS 2026.docx:** Doble Percepción, Acta de Inducción, Acta de Posesión y Declaración de Incompatibilidades/Conflicto de Interés/Prohibiciones.
- **avance.xlsx:** columnas de control que actualmente maneja Kardex, entre ellas ítem, unidad administrativa, denominación, puesto funcional, haber mensual, ubicación/CIP, CI, LSM, FELCC, REJAP, CENVI, Aymara, ficha, hoja de vida, CUA, inamovilidad y formación académica.
- **01 MULLISACA MAMANI GROBER TITO.xlsx:** estructura del formulario de Denuncia de Accidente de Trabajo (anverso y reverso), incluida la clasificación A–G.
- Entrevistas de levantamiento con Kardex y Recursos Humanos: flujo de ingreso, coordinación con RR.HH., Caja de Salud, vacaciones, certificados, historial y otros procesos.

## Campo a confirmar
`PUESTO FUNCIONAL2` aparece como una columna adicional en `avance.xlsx`. El prototipo lo muestra expresamente para que Kardex confirme si es un dato distinto o una duplicación de `PUESTO FUNCIONAL` antes de crear la tabla definitiva.

## Regla de archivos
No se incluyó carga de documentos digitalizados. El prototipo conserva únicamente datos y estados de control/checklist.

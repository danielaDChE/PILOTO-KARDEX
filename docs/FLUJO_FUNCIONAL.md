# Flujo funcional propuesto – Kardex

1. **Pre-registro:** Kardex identifica al interesado por C.I. y, si ya se conoce, N° de ítem.
2. **Checklist de requisitos:** se controlan los 25 requisitos como Presentado / Pendiente / No corresponde. No se adjuntan archivos.
3. **Conformidad a RR.HH.:** cuando los requisitos aplicables están completos, Kardex remite la conformidad.
4. **Memorándum de Designación:** RR.HH. realiza su proceso y Kardex recibe el número/fecha del memorándum.
5. **Registro completo:** se actualizan Ficha Personal, Hoja de Vida, datos institucionales, bancarios y de seguridad social.
6. **Formularios de ingreso:** Posesión, Inducción, Doble Percepción e Incompatibilidades se llenan con datos existentes y se generan para impresión.
7. **Kardex activo:** se habilitan procesos recurrentes: Familia/Parentesco, Caja de Salud, Vacaciones, Certificados y Accidentes de Trabajo.
8. **Historial:** cada operación relevante genera un evento cronológico reutilizable en certificados y consultas.

## Principio de normalización
Los datos de Persona, Ítem, Seguridad Social y Vinculación se registran una sola vez y se reutilizan. Por ejemplo, un accidente no vuelve a guardar nombre, C.I., fecha de nacimiento, CUA o fecha de ingreso; el formulario los autocompleta desde Kardex.
